### SHIFT BALANCE ##
Computer science thesis project.

## Overview
ShiftBalance is a .NET 8 web application designed to assist in managing and balancing work shifts efficiently.
The tool aims to optimize shift assignments using linear programming optimization, ensuring fair distribution of work hours among employees.
Automatically assigns shifts to employees based on predefined criteria to ensure balanced workloads, generates a .xlsx file with the full schedule using either a matrix algoritm or linear programming optimization.

For the linear programming optimization I used Google OR-TOOLS library: https://developers.google.com/optimization/install/dotnet
